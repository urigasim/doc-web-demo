# DGC 자체 웹 플랫폼 — VS Code 실행용 프로토타입 v2

첨부된 `DGC 자체 웹 플랫폼 설계안` PPT를 바탕으로 만든 브라우저 실행용 프론트엔드 프로토타입입니다. 기존 통합 관제·사고 초동대응·작업자·로봇·설정·보고서 화면에 멀티 CCTV 감시와 디지털 도면 마커 매핑, 버튼별 기능 설명 창을 추가했습니다.

## 실행 방법

1. ZIP을 풀고 `dgc-web-prototype` 폴더를 VS Code에서 엽니다.
2. VS Code의 **Live Server** 확장 프로그램이 있다면 `index.html`에서 마우스 오른쪽 버튼 → **Open with Live Server**를 선택합니다.
3. 브라우저에서 왼쪽 메뉴를 눌러 각 화면을 확인합니다.

별도 패키지 설치나 빌드 과정은 필요하지 않습니다. `index.html`을 직접 열 수도 있지만, 도면 마커의 브라우저 저장 동작을 안정적으로 확인하려면 Live Server 실행을 권장합니다. Google Fonts가 차단된 환경에서는 시스템 기본 글꼴로 표시됩니다.

## 이번 버전에 추가한 기능

### 1. 멀티 CCTV 감시

- CCTV 4채널(CAM-01~CAM-04)의 데모 피드를 한 화면에서 확인합니다.
- 카메라 카드를 누르면 해당 채널이 메인 화면으로 전환됩니다.
- **움직임 감지 테스트**를 누르면 Warning 이벤트를 생성하고 해당 카메라를 자동 선택·확대합니다.
- **경계 발동 테스트**를 누르면 Critical 경계 침범 예시를 생성하고 감지 박스와 경계 배너를 표시합니다.
- **자동 감지 켜기**는 약 18초 간격으로 가상 이벤트를 만들며, 자동 감지 끄기로 종료할 수 있습니다.
- 감지 이벤트 이력이 CCTV 화면과 기존 이벤트 데이터에 추가됩니다.

### 2. 디지털 도면 매핑

- PNG, JPG/JPEG, WebP, SVG 이미지와 PDF 파일을 브라우저에서 미리 봅니다.
- `CCTV 배치`, `작업자 위치`, `위험구역` 중 유형을 선택한 다음 도면을 클릭하면 해당 위치에 마커가 추가됩니다.
- 마커를 누르면 상대 좌표와 기능에 대한 설명을 확인합니다.
- `마지막 마커 삭제`로 잘못 놓은 마커를 제거할 수 있습니다.
- `도면 배치 저장`은 마커 좌표를 해당 브라우저의 로컬 저장소에 저장합니다.

### 3. 버튼별 상세 설명

왼쪽 메뉴를 선택하거나 대부분의 기능 버튼을 누르면 설명 창이 열립니다. 설명 창에는 기능 목적, 조작 순서, 현재 데모의 제한 사항이 표시됩니다. 설명 창 오른쪽 위의 `×`, 아래쪽 `확인`, 또는 `Esc`로 닫을 수 있습니다.

### 4. 기존 PPT 기반 화면

- 통합 관제: 위험 등급 요약, 위치 지도, 이벤트 목록, 4티어 상태
- 사고 초동대응: 위험 배너, 1차/2차 판단, 대응 가이드, 타임라인
- 작업자: 가상 위치와 장치 상태, 모바일 경고 화면 예시
- 로봇: 순찰 상태 및 2차 확인용 화면 예시
- 도면·규칙: 구역별 위험 규칙 켜기/끄기
- 설정: 비식별화, 연동 정책, 보안 검토 항목
- 보고서: 검색, 등급 필터, CSV 내보내기

## 반드시 알아둘 제한 사항

현재 결과물은 **화면 시연용 프론트엔드 초안**입니다.

- CCTV 화면은 CSS로 만든 가상 장면입니다. 실제 CCTV/RTSP/ONVIF 스트림, 객체 인식 AI 또는 영상 분석 모델에 연결되어 있지 않습니다.
- 움직임 및 경계 침범은 버튼 또는 데모 타이머로 생성되는 가상 이벤트입니다. 실제 경계 발동·경광등·방송·소방 호출·PLC 제어는 일어나지 않습니다.
- 도면 파일은 화면 미리보기만 제공하며 CAD의 DWG/DXF 직접 파싱, PDF 자동 벡터화, 축척 보정, 실제 좌표계 정합, 자동 객체 인식은 구현 전입니다. CAD 도면은 PDF나 이미지로 내보내서 올려 주세요.
- 마커 좌표는 표시 영역 기준 상대 좌표입니다. UWB, 카메라 캘리브레이션, GIS/BIM/CAD 좌표와 일치한다고 볼 수 없습니다.
- 업로드한 도면 파일은 현재 브라우저 세션의 미리보기입니다. 계정 간 공유나 서버 저장은 되지 않습니다. 마커 좌표 저장은 현재 브라우저의 로컬 저장소에만 이루어집니다.
- 실제 운영 전에는 서버/API, 사용자 인증과 권한, 이벤트 감사 로그, 네트워크 보안, 개인정보·영상 보존 정책, 오탐 검토와 현장 안전 절차를 별도로 설계해야 합니다.

## 파일 구성

- `index.html` — 앱 프레임, 메뉴, 설명 모달, 도면 파일 선택 입력
- `style.css` — 디자인, CCTV 가상 피드, 반응형 레이아웃
- `app.js` — 각 화면, 클릭 동작, 데모 이벤트, 마커 좌표 처리
- `README.md` — 실행 방법과 구현 범위
